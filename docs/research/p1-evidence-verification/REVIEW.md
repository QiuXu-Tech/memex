# P1 独立审查与处理记录

日期：2026-11-28（Asia/Shanghai）。范围：新的研究组件、统计分析器、基线适配器、原生 smoke 和工作稿。独立审查与回归测试用于检查实现；它们不构成论文实验结论或生产部署批准。

| 审查发现 | 处理 | 验证依据 |
|---|---|---|
| 成本字段损坏曾把本来成功的运行转为质量失败，可能制造虚假的 D−B 优势 | 质量与成本分别解析；坏成本保留为未知并阻断成本确认，不改变有效质量；未知质量或损坏研究记录阻断确认 | 24 任务、8 项目、72 条成功运行、18 条坏 B 成本的回归：72 次成功，D−B=0，H1=false |
| 修改缓存来源内容并重算自身 hash 可能伪造缓存证据 | 缓存必须匹配可信 archive head 的内容承诺，而不只核对自身 hash；半写入缓存作为 miss | 新增缓存篡改、head mismatch 与半写入回归 |
| `node printer.js --test` 可能被误当真实测试命令 | 限定可支持的 Node argv 和 shell envelope；`--test` 必须是 Node 首个选项；拒绝 eval、shell 组合和未声明 executable | 命令伪装回归及真实 Node 子进程解析测试 |
| 水位原先局限于查询实体，文稿又把完整部署协议写成已完成能力 | 水位改为整个 session catalog；明确可信完整状态快照假设；文稿第 4 节标为目标协议，第 5.3 节说明实际边界 | 无关实体更新回归；21 页 PDF 重新构建和逐页检查 |
| Raw-RAG 公开 source 白名单拒绝共享 Node/authorization 来源中的合法字段 | 补全共享字段；不删除来源信息来迁就基线 | 两个跨臂测试经真实 Memex L2 和 verifier，再由 Raw-RAG validator 接收 |
| 原生 smoke 曾仅凭输出含 `# pass 1` 判定执行成功 | 使用共享 Node/TAP normalizer 验证唯一、确实执行的命令、版本、退出码与实际测试数 | echo、重复 receipt 和非精确 test count 回归；实际 Mac 续跑验证 |
| claims extractor 收到 null 响应会崩溃 | 将其记录为失败输出，不静默当作无 claim 或成功 | null 响应回归 |

## 明确保留的限制

这些修复没有证明一般自由文本日志的正确归一化、真实任务 claim 抽取的完整性、多写入者 archive 一致性、任意外部变化检测或模型对证据的正确使用。当前完整视图由受信任的单写入 host observer 声明；没有 observer 的覆盖保证，核验器不能证明“不存在未见的撤销或版本变化”。

默认预算尚未构成冻结的跨臂总预算；实际 Raw-RAG 调用和供应商账单未取得；正式任务与人工义务标注未完成。审查未作接受论文或投稿准备完成的判断。

审查后发生的原生宿主协议兼容修复另有定向回归与真实运行记录。失败尝试保持可见；不删除失败轮次后只展示成功摘要。
