### 2.2 技术上界及阶段预留

- 18 个 generation 与 2 个 compaction 合计最多 20 次 HTTP；provider HTTP 本身也占控制器 public-tool-call 计数，不能重复给出 64 次额外工具调用。

### 2.3 费用上界的离线复算

2026-11-29 Asia/Shanghai（2026-11-28 UTC）重新读取 DeepSeek 官方价格：`deepseek-flash` 峰时未缓存输入 CNY 2/百万 tokens、输出 CNY 8/百万 tokens，公布上下文 1M。估算使用较高的峰时未缓存费率，不依赖周末或缓存折扣。[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

```text
已知累计前缀上界 = (393216 × 2 + 16384 × 8) / 1000000
                 = CNY 0.917504
最后一个未知/越界请求上界
                 = (1048576 × 2 + 8192 × 8) / 1000000
                 = CNY 2.162688，继续按 CNY 3.00 保守留存
所需预留         = ceil_to_fen(0.917504 + 3.00)
                 = CNY 3.92 ≤ 拟预留 CNY 4.00
四次新增预留     = 4 × 4.00 = CNY 16.00
历史承诺 + 本批  = 15.80 + 16.00 = CNY 31.80
原总额余量       = 100.00 - 31.80 = CNY 68.20
```

该证明依赖同 scope 串行 dispatch、不可变 completion 与实际用量完整握手、关闭服务端工具、一次仅一个未知末请求、固定单次输出，以及执行当天价格/型号核验。未实现或验证这些条件时不启动。若价格变化致 4 元无法覆盖，停止并重新提供具体方案。每 scope 未使用的预留不因 token 估算自动核销，实际费用仍待账单证据。

原 16 个方法 scope 沿用当前每个 generation reader CNY 3.20 的保守基数，共 CNY 51.20；若全执行，以上容量仅余 CNY 17.00 可容纳 B 检索及其他仍合法的预留。B 价格未核实，因此 **不保证 100 元能覆盖全部完整四臂执行**；所有调用仍受同一现金账本准入，余额不足即停止。未核实的 CNY 0.50/次示例不作为报价。
