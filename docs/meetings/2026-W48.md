# W48 Memex 组会技术纪要

会议于北京时间 2026-11-25 举行。组长主持，工程成员提交实际接口及热点意见，复核成员提交反例和验证要求。两位成员的实际发言保存在内部。资料及选读范围见[本周来源](sources/2026-W48.md)。

W47 的组装微基准覆盖排序和预算构造。W48 的争议是能否把组装收益直接换算成工具请求收益。工程确认普通 search、带预览的 search 和独立 open 是不同的实际入口。复核指出，同一条记录先经全文检索进入候选，后续数字救回仍可能改写其摘要和得分。主持据此采用真实 MCP 响应的配对测量，并保留候选顺序、正文补召、到期、删除及工作区和会话隔离作为验收条件。

| 轮次 | 责任人和验证 |
| --- | --- |
| R1 | 工程建立隔离归档与实际 stdio 入口基线。组长固定请求组和统计口径。复核检查入口映射和相同数据上的结果。 |
| R2 | 组长按诊断减少首条匹配行提取的开销，保留搜索顺序、扫描范围和汇总。复核使用独立动态用例核对结果。 |
| R3 | 工程围绕 R2 未解决的成本提出有界候选，组长按同一负载复测，复核检查连接生命周期及最新参数和结果。 |

会议保留混合端到端中位降时 30% 的目标。动态正确性优先，测不到预期收益就保留结果和复现方法。跨请求缓存搜索结果要求进一步的失效和一致性证据。语义重排和多路检索需独立质量试验。
